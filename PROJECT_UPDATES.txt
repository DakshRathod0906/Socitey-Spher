5. FORGOT & RESET PASSWORD FLOW
--------------------------------------------------------------------------------
• Mongoose Schema Update (`backend/models/User.js`):
  - Added `resetPasswordToken` and `resetPasswordExpires` fields.
• Backend Service Logic (`backend/services/auth/AuthService.js`):
  - `forgotPassword(email)`: Generates a 64-character SHA-256 token (expires in 1 hour) and dispatches an email via Nodemailer.
  - `resetPassword(token, newPassword)`: Validates token expiration, hashes new password with `bcryptjs`, and updates user account.
• Backend Routes:
  - Added `POST /api/auth/forgot-password` and `POST /api/auth/reset-password` in `backend/routes/authRoutes.js`.
• Frontend Pages:
  - Created `ForgotPassword.jsx` (`frontend/src/features/auth/ForgotPassword.jsx`).
